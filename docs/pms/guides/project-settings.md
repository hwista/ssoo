# 프로젝트 사용 설정

> 2026-09-21 · 승인-13 적용 범위 및 카드·목록·타임라인 표시 보완

사용자 메뉴의 **프로젝트 사용 설정**에서 본인 계정의 옵션을 저장한다. 개인 설정의 프로필·비밀번호 변경은 기존 동선을 유지한다. 직접 접속 주소는 `/project-settings`이며 로그인 후 복귀·새로고침을 지원한다. 기존 `/settings` 직접 접속은 개인 설정이다.

| 선택 | 적용 범위 | 초기값 |
|---|---|---|
| 완료된 작업 표시 | 프로젝트 태스크 목록. 완료 항목만 숨기고 숨긴 수·다시 표시 버튼을 제공한다. 취소 작업·전체 공수 집계·공수 입력 대상은 유지한다. | 표시 |
| 내 프로젝트 기본 보기 | 동일한 조회 범위의 보드(기존 카드)·목록·타임라인. 모든 보기에서 상세를 연다. | 보드 |
| 작업 배정 알림 | 작업 생성·실제 담당자 변경 시 새 담당자. 자기 배정·해제·동일 값은 제외한다. | 켜짐 |
| 이슈 변경 알림 | 정식 이슈의 실제 내용·유형·상태·우선순위·담당자·기한·해결 정보 변경 시 현재 담당자와 등록자. 중복 수신자와 작업자는 제외한다. | 켜짐 |

타임라인은 현재 단계의 예정 시작·종료일을 사용한다. 기간 누락은 일정 미정, 일부 누락·역전은 기간 확인 필요로 표시한다. 일정을 끌어서 수정하지 않는다.

내 프로젝트의 보드, 조치 필요, 종료/전환, 전체 운영 현황에서 사용하는 프로젝트 카드는 제목·번호·상태 아래에 고객사·자산·업무 안내를 세로로 배치한다. 같은 행의 카드는 상단부터 내용을 표시하고, 긴 고객사·자산 정보는 카드 안에서 줄바꿈한다. 제목의 기존 말줄임, 표시 항목, 클릭·키보드로 상세를 여는 동작은 유지한다.

목록은 프로젝트·단계/상태·고객사/자산·담당자·최근 수정 순서를 유지하며, 최소 960px 읽기 폭보다 화면이 좁으면 표 내부에서 가로로 이동한다. 프로젝트명과 고객사/자산은 긴 문구를 줄바꿈하고, 단계·담당자·날짜는 한 줄로 읽을 수 있게 한다. 목록과 타임라인의 제목 버튼은 내용만큼 높이가 늘어나므로 프로젝트 번호와 겹치지 않는다. 타임라인의 일정 표시와 세 보기의 조회 범위·설정 저장·상세 열기 동작은 유지한다. [2026-09-21 검증 결과](../../../output/playwright/pms-list-fix-20260921/results.md)에서 짧은/긴 이름, 보기 저장·새로고침·원래 설정 복원을 확인했다.

설정 저장은 서버 성공 후 반영한다. 실패 시 기존 값을 유지하고 재시도 버튼을 제공한다. 설정 조회 실패 시 작업은 전체 표시, 내 프로젝트는 보드로 안전하게 표시하고 다시 확인할 수 있다. 다른 기기에서는 화면 진입·포커스 복귀와 30초 주기 재확인으로 최신 값을 받는다. 이전 소유자 없는 브라우저 저장값은 자동 이관하거나 삭제하지 않는다.

작업 담당자는 현재 프로젝트에 접근 가능한 활성 멤버만 새로 지정할 수 있다. 이전 담당자 표시는 유지한다. 기존 작업 관리 권한을 서버에서 적용한다. 알림을 끄면 이후 해당 종류만 생성하지 않으며 이미 받은 알림·보고서 승인 등 다른 알림은 유지한다. 다시 켤 때 소급 알림을 만들지 않는다.

업무 저장과 알림 기록을 한 트랜잭션으로 처리한다. 알림 기록 실패는 업무 변경도 취소한다. 같은 작업·이슈에 대한 동시 재저장은 저장된 값을 비교해 중복 알림을 만들지 않는다. 같은 작업 코드를 다시 등록하면 중복 안내와 함께 거절한다.
