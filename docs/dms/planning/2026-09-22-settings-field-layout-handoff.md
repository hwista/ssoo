# 문서관리 설정 입력 행 배치 핸드오프

> 작성: 2026-09-22 · 상태: 사용자 승인 적용·새 빌드·브라우저 검증 완료

## 승인 범위

사용자는 [설정 화면 비교안](../../../output/playwright/dms-settings-review-20260922/review.html)을 제시한 뒤 “진행”으로 10개 설정 메뉴의 배치 수정을 승인했다. 개인 설정은 작성자 정보·기본 저장소·문서 확대 배율·메뉴 기본 펼침의 4개, 시스템 설정은 첨부 저장소·수집 큐·업로드 한도·검색·문서 보조·문서 분석/추출의 6개다.

사전 검사에서 18개 메뉴를 네 화면 폭으로 확인했고, 768px에서 10개 메뉴의 35개 입력 항목이 항목명 압축·입력란 겹침을 보였다. 이는 기존 설정 화면 품질 잔여의 처리이며 별도 업무 기능 추가나 기존 승인 대장 번호 신설이 아니다.

## 적용 내용

기존 입력 행은 브라우저가 768px 이상이면 좌우 배치를 강제했다. 펼친 메뉴를 제외한 실제 입력 행 폭이 320px일 때 입력란 308px와 간격 12px가 공간을 모두 사용해 항목명 칸이 0px로 줄어들었다.

DMS의 기존 JSON 입력 행에 크기 컨테이너를 지정하고, 실제 행 내부 폭이 559px 이하이면 한 칸으로 전환한다. 항목명 → 입력란 → 오류 안내 순서를 유지하며, 충분한 폭에서는 기존 좌우 배치를 사용한다. 승인 비교안과 동일한 560px 전환 기준을 적용하고 새 래퍼·상태·관측 코드를 추가하지 않는다.

공용 입력 원자, 항목명·문구·옵션·입력값·변경 표시·오류 판정·저장 기준과 서버 계약은 보존한다. 별도 구성을 사용하는 권한 관리·결재선·산출 정책·템플릿 및 운영 상태 화면은 입력 행 변경 대상이 아니다. 공용 패키지와 다른 서비스는 수정하지 않는다.

## 검증과 제한

[실제 적용 화면](../../../output/playwright/dms-settings-apply-20260922/screens.html)과 [검증 상세](../../../output/playwright/dms-settings-apply-20260922/results.md)를 참조한다.

- 18개 설정 메뉴의 기본 네 폭과 수정 대상 10개 메뉴의 추가 세 폭, 총 102개 상태에서 항목명 압축·입력란 겹침·입력란 경계 이탈 0건.
- 승인 전 미리보기와 공통 72개 상태의 입력 행 좌표·크기 일치. 입력 행이 없는 별도 구성 화면은 이 비교로 전체 품질 통과를 판정하지 않는다.
- 문자 입력의 화면 크기 전환 6회, 선택·체크 입력의 크기 전환 9회 값 유지와 저장 버튼 활성 확인. 개인 설정 3종의 초기화 및 기존 이메일 오류 안내·저장 차단 유지.
- 최종 관련 브라우저 실행·통신 오류 0건. 실제 설정 저장 요청 없음.
- 작업 전후 사전 검사, 규칙 동기화, 문서관리 보호 검사와 작업공간의 새 빌드, 변경 파일 문법·패턴·디자인 및 스타일 경계 검사 통과.

별도 검증 포트의 새 빌드에서 임시 스타일 없이 확인했다. 격리 빌드의 검사 도구 모듈 탐색 오류는 별도 로그에 보존했으며, 실제 작업공간의 전체 보호 빌드·변경 파일 문법 검사를 통과한 근거와 분리한다. 빌드가 끝나기 전 시도한 초기 실행은 제외하고 빌드 완료 후 다시 실행했다.

검증 범위는 설정 입력 행의 배치·입력 유지·저장 버튼 접근성과 기존 오류 안내다. 실제 설정 저장·권한 변경·결재선 변경·운영 제어는 실행하지 않는다. 기존 테스트 배포도 교체하지 않는다. 설정 메뉴 전체 기능 또는 전체 서비스 출시 품질 완료를 뜻하지 않는다.
