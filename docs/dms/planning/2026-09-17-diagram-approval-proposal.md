원문 저장 형식, 문서 경로, 읽기/쓰기 요청·응답, 공유·권한·협업 잠금, 검색 조건, 기존 문서 내용과 공통 서비스 기본 배치는 변경하지 않는다. 문서관리의 해당 도구 모음에만 좁은 화면 배치 선택을 적용한다. 도형 표시를 위해 문서 정화·안전한 처리 기준을 낮추지 않는다. 인공지능 답변의 기존 다이어그램 표시는 유지하며 관련 회귀 확인만 한다.

문서 검색이 도식 원문을 찾는 기존 동작도 유지해야 한다. 도형 전환으로 검색 결과가 사라지거나 보이지 않는 위치를 가리키면 완료가 아니다. 검색으로 찾은 도식은 원문을 펼쳐 기존 검색 위치를 확인할 수 있게 하는 범위까지 이 승인안에 포함한다.

## 승인 후 실행 순서

1. 읽기 화면의 실행 원인을 재현·분리하고 기존 도형 부품을 재사용하는 최소 보정안을 구현한다. 비동기 도형 생성 중 문서·탭·내용이 바뀌어도 다른 문서를 덮지 않게 한다.
2. 읽기·편집 미리보기·템플릿 미리보기에서 정상 도형, 원문 확인, 오류 원문, 일시 오류 재시도를 맞춘다. 편집 원문·저장·검색 보존을 확인한다.
3. 인쇄용 문서에 같은 정상 도형/실패 원문을 반영한다. 일반 코드·표·이미지·줄바꿈·원문 내려받기를 비교한다.
4. 문서관리의 작은 화면 도구 겹침을 보정한다. 기능을 없애거나 숨기는 방식으로 해결하지 않는다.
5. 아래 검증과 기존 문서 업무 회귀를 마친 뒤 큰 화면·휴대폰 결과를 사용자에게 제시한다. 통과 전 승인-15를 완료로 집계하지 않는다.
