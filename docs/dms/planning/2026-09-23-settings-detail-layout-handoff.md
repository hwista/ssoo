# 문서관리 별도 설정 배치·조회 실패 처리 핸드오프

> 작성: 2026-09-23 · 상태: 승인 범위 적용·새 빌드·브라우저 검증 완료, 별도 가림 잔여 기록

## 승인 범위

사용자가 [8개 메뉴 검토와 비교안](../../../output/playwright/dms-settings-detail-review-20260923/review.html)에 “승인”으로 동의한 범위다. 문서 권한 관리, 계약 결재선, 계약 산출 정책, 수집 큐 상태, 관리자 템플릿의 5개 화면 배치와 템플릿 조회 실패 안내를 적용한다. 기존 설정 품질 잔여의 후속 처리로, 정식 승인 번호를 새로 추가하지 않는다.

## 변경 내용

- 소유권 이전: 실제 입력 영역이 400px보다 좁으면 입력란을 버튼 위로 배치한다.
- 계약 설정 2개: 실제 내용 영역이 560px보다 좁으면 항목을 한 열로 표시하고, 읽기 전용 식별자·경로는 줄바꿈한다.
- 수집 큐: 실제 작업 등록 영역이 720px보다 좁으면 입력란과 등록 버튼을 세로 배치한다.
- 관리자 템플릿: 목록 버튼 묶음이 내용 영역 안에서 줄바꿈된다.
- 위 화면들의 하단에 여백을 확보하여 마지막 작업 버튼에 대화 버튼이 겹치지 않도록 한다.
- 템플릿 조회 오류와 응답의 `success:false`를 실제 빈 목록과 구분한다. 실패 안내와 “다시 불러오기”를 제공하며, 기존 조회를 다시 실행한다. 작성 중인 이름·설명·본문 상태를 초기화하지 않는다.

DMS 기존 컨테이너 질의 배치 패턴과 공용 버튼을 재사용한다. 새 공용 구조나 의존성을 추가하지 않는다. 기존 저장·삭제·검토 확정·업로드·권한 이전·작업 등록 처리와 서버 계약은 유지한다. 계약 결재선 화면은 역할 기록 생성 설정이며, 담당자 지정·승인 요청 기능이 구현됐다는 뜻이 아니다.

## 검증

[실제 적용 화면](../../../output/playwright/dms-settings-detail-apply-20260923/screens.html)과 [실행 증거](../../../output/playwright/dms-settings-detail-apply-20260923/results.md)를 참조한다.

- 새 빌드·문서관리 보호 검사·사전 검사·규칙 동기화·수정 코드 검사·스타일 경계·공용 원자 소비 검사 통과.
- 8개 메뉴 × 5개 너비의 기본 40상태에서 입력란·버튼 화면 밖 이탈 0건. 별도 입력 중 배치 25상태에서는 권한 이전 입력 폭, 좁은 계약 설정의 한 열 배치, 읽기 전용 값 잘림, 하단 작업 버튼 접근성을 확인했다.
- 입력·검증·되돌리기 12/12, HTTP 실패·연결 실패·반복 실패·빈 목록/실제 목록 복구·작성 내용 유지 14/14 통과. 키보드 Enter 재조회도 포함한다.
- 권한 이전 양식은 실제 중앙 스크롤 후 다섯 너비에서 취소를 실행했다. 모든 임의 스크롤 위치의 가림 해소를 뜻하지 않는다. 아래 잔여를 별도로 유지한다.
- 검증용 실패 응답 2회와 연결 실패 1회는 예상된 실패 주입이다. 그 외 최종 브라우저 오류·업무 데이터 변경 요청 0건.
- 실제 저장·삭제·확정·소유권 변경·작업 등록은 실행하지 않았다. 기존 처리 코드를 유지했고, 대표 다섯 비교 상태에서 버튼 문구·활성화 상태가 이전과 일치한다.
- 격리 빌드의 이전 추적 산출물로 인한 재빌드 실패는 해당 산출물 보관 후 해소했다. 최종 빌드 입력 564개와 현재 DMS·공유 코드가 일치한다. 회사 배포는 변경하지 않았다.

## 남은 작업

후속 상태(2026-09-23): 아래 잔여 중 설정 제목·항목명·용어·날짜·운영 상태 문구와 떠 있는 대화 버튼의 본문 가림은 사용자의 “적용하자” 승인에 따라 후속 수정했다. 현재 검증과 새로 확인한 작은 화면 대화 도구 잘림은 [설정 잔여 후속 핸드오프](2026-09-23-settings-residual-handoff.md)를 따른다. 아래는 이번 수정 이전의 잔여 기록이다.

이번 승인 범위 밖의 빈 상단 제목·내부 이름으로 표시되는 현재 위치, 서식 등록 항목명·운영 용어, 기본 서식의 1970년 날짜, 운영 연결 상태를 뜻하는 “런칭 준비됨” 문구는 아직 수정하지 않았다. 공통 제목 변경은 설정 18개 메뉴에 영향을 줄 수 있어 비교안과 승인이 필요하다. 검색창 배경 차이도 미재현 잔여다. 추가로 권한 이전 양식이 중간 스크롤의 화면 하단에 걸리면 떠 있는 대화 버튼이 취소 버튼 일부를 덮는 상태를 확인했다. 이 상태에서도 버튼 중심 클릭으로 취소됐고 중앙으로 스크롤한 뒤에도 취소를 확인했지만, 시각적인 가림 자체를 해결했다고 집계하지 않는다. 공용 대화 버튼 위치·회피 동작 변경은 별도 비교안과 승인 대상으로 남긴다.

다음은 제목·항목명·용어·날짜 표시의 구체 비교안을 검토하고 승인받는 단계다. 이번 변경은 전 서비스 품질 완료나 회사 배포 반영이 아니다.
