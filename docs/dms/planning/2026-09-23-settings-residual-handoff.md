# 문서관리 설정 잔여 표시·대화 버튼 후속 핸드오프

> 작성: 2026-09-23 · 상태: 승인 범위 적용·검증 완료, 후속 대화 도구 잘림도 해결

## 승인과 적용 범위

사용자의 “적용하자”는 [설정 잔여 수정안](../../../output/playwright/dms-settings-residual-review-20260923/review.html)에 대한 실행 승인이다. 기존 화면 품질 보완의 후속으로 정식 승인 번호를 신설하지 않는다.

| 화면 | 적용 내용 |
|---|---|
| 설정 18개 메뉴 | 상단 제목·한글 현재 위치, 대화 열기 버튼을 상단 작업 영역에 배치. 작은 화면에서 작업 버튼 줄바꿈 |
| 개인 설정 4개 | 작성자 정보·기본 저장소·문서 보기·메뉴 기본 펼침으로 메뉴/탭 제목 정리. 이미 저장된 탭 제목도 갱신 |
| 서식 관리 | 여섯 입력 항목명을 입력 후에도 유지. 날짜 누락·잘못된 값·1970년 대체값은 ‘수정일 정보 없음’, 실제 날짜는 유지 |
| 권한·계약 설정 | 표시 항목명과 안내를 한글로 정리. 정책 식별자·버전·역할·실제 경로는 그대로 표시 |
| 운영 진단 | 항목명을 풀어 쓰고 ‘런칭 준비됨’을 ‘운영 연결 정상’으로 변경. 차단·확인 불가·유효 시간 판정과 서버 진단 사유 유지 |

설정에서만 떠 있는 대화 버튼과 드래그를 상단 버튼으로 대체한다. 대화창에는 설정에서 사용할 닫기 버튼을 제공한다. 문서 화면의 기존 떠 있는 버튼·드래그·원위치 복귀·닫기·초안은 유지한다. 설정의 로딩·권한 오류에서도 대화 진입을 보존한다.

서버·공용 패키지·저장 처리·요청/응답 계약을 바꾸지 않는다. 계약 결재선은 기존 역할별 문서 생성 설정이며 실제 담당자별 결재 기능을 추가한 것이 아니다. 회사 배포도 수행하지 않는다.

## 검증 기록

최종 실행 결과와 승인 범위 밖의 발견 사항은 [실행 증거](../../../output/playwright/dms-settings-residual-apply-20260923/results.md)에 분리해 기록한다. 검증은 회사 배포가 아닌 격리된 로컬 빌드에서 수행한다.

- 설정 18개 메뉴 × 5개 너비(1440·1024·768·390·320px), 총 90상태에서 제목·한글 현재 위치·상단 대화 버튼·본문/작업 버튼의 화면 밖 이탈을 확인했다. 이 범위 실패 0건.
- 계약·권한·서식 입력/검증/되돌리기 12/12, 서식 항목명·실제/누락 날짜·기존 탭 제목·개인 입력 보존 20/20 통과.
- 서식 조회의 HTTP 실패·연결 실패·반복 실패·빈 목록/실제 목록 복구 14/14 통과. 의도한 실패 3회와 그에 따른 오류 기록은 일반 오류와 구분한다.
- 운영 상태 4종과 유효 시간 만료 표시 14/14 통과. 조회 응답만 바꾼 브라우저 검증이며 실제 운영 연결 상태를 바꾼 것이 아니다.
- 대화/가림 검사 34개 중 승인 범위 동작 32개 통과, 기존 작은 화면 대화 도구 잘림 2상태는 실패로 남겨 후속 1건 승인 대기로 묶었다. 원래 가림이 있던 소유권 이전 입력 위치에서 취소·대화 열기/닫기·초안 유지, 실제 문서의 기존 드래그·원위치 복귀를 확인했다.
- 새 빌드·문서관리 보호 검사·사전 검사·문서 검사·수정 코드 검사·스타일 경계·공용 부품 소비·규칙 동기화 통과. 최종 빌드의 문서관리/공유 입력 765개와 현재 코드가 일치한다.
- 최종 정상 시나리오의 브라우저 오류·차단된 업무 변경 요청은 0건. 저장·삭제·확정·권한 변경·대화 전송은 수행하지 않았다. 문서 열람 요청은 실제 서버를 사용하고, 접속 이력·읽음 표시·공동 열람 상태는 브라우저 응답으로 대체했다. 해당 부수 효과의 실제 저장 검증은 이번 범위가 아니다.

[적용 화면 모음](../../../output/playwright/dms-settings-residual-apply-20260923/screens.html)에서 대표 화면을 확인할 수 있다. 상단 제목/대화 진입은 설정에 국한하고 기존 상태 저장소를 재사용했으며, 소스 차이 검토에서 서버 계약·저장 처리의 변경이 없음을 확인했다. 별도 승인 대기 문제를 전체 통과로 합산하지 않는다.

## 남은 작업과 승인 경계

후속 완료(2026-09-23): 사용자 “승인” 후 [대화 도구 배치 수정](2026-09-23-assistant-history-layout-handoff.md)을 적용·검증했다. 아래 1번은 당시 승인 대기 기록이며 현재는 해결됐다. 별도 승인 대기 0건, 검색 배경 차이의 미재현 상태는 유지한다.

1. **작은 화면의 대화 도구 잘림: 별도 승인 대기.** 320·390px에서 대화창 바깥 왼쪽에 놓인 ‘새 대화·대화 기록’ 버튼이 화면 밖으로 나간다. 이전 소스에도 같은 바깥 배치와 대화창 폭 계산이 있으며, 이번 설정 상단 버튼 이동과 별개다. [후속 비교안](../../../output/playwright/dms-settings-residual-apply-20260923/history-review.html)은 작은 화면에서 두 도구를 제목 아래에 배치하고 기록 목록도 창 안에 표시하는 안이다. 문서 화면에도 영향을 주므로 사전 승인 원칙에 따라 확인을 요청했다. 현재는 브라우저 표시 실험만 수행했으며 제품에 적용하지 않았다.
2. **검색창 배경 차이: 미재현.** 이번 설정 변경으로 해결됐다고 집계하지 않는다. 다음 품질 점검에서 동일 조건의 화면을 비교해 재현 여부와 원인을 확인한다.

이는 이번 설정 승인 범위와 검증 중 발견한 잔여의 목록이다. 전체 서비스 품질 완료율 또는 모든 화면 결함 수를 뜻하지 않는다. 기존 정식 승인 대장의 22항목·21완료·1운영 보류는 유지한다.
