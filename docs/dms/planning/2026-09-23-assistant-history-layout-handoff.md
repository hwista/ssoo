## 승인과 변경

사용자 “승인”은 [대화 도구 후속 비교안](../../../output/playwright/dms-settings-residual-apply-20260923/history-review.html)의 실행 승인이다. [설정 잔여 핸드오프](2026-09-23-settings-residual-handoff.md)에서 승인 대기로 남겼던 동일 문제 1건을 처리한다.

- 640px 미만에서는 새 대화·대화 기록 버튼을 대화창 제목 아래 가로로 표시한다.
- 작은 화면의 기록 목록은 대화창 안에서 열리고 길면 목록 안에서 스크롤한다.
- 640px 이상에서는 기존 왼쪽 도구·기록 목록 배치를 유지한다.
- 기록 버튼의 펼침 여부를 접근성 속성에 연결한다.

설정 화면과 문서 화면이 사용하는 대화 도구 한 곳의 배치만 수정했다. 버튼 이름·목록 내용·기록 선택·새 대화·확대 보기·대화창 열기/닫기·드래그·저장/전송 처리와 서버 계약은 보존한다. 새 대화와 기록 선택 시 초안을 초기화하는 기존 동작도 유지한다. 일반 열기/닫기와 기록 목록 열기/닫기는 작성 중 초안을 유지한다.

최종 브라우저 오류·예상하지 않은 업무 변경 요청은 0건이다. 대화 목록은 긴 제목 6개와 빈 목록을 브라우저 응답으로 제공했다. 문서 조회는 실제 서버를 사용했고, 접속 이력·알림 읽음·공동 열람과 기록 선택으로 발생하는 기존 자동 저장은 검증용 응답으로 대체했다. 대화 전송·실제 기록 저장의 검증을 수행했다는 뜻은 아니다. 초기 로그인 렌더링 대기 문제는 검사 순서를 보정한 후 재실행했다.

새 의존성·공용 패키지·상태 관리·업무 처리 변경 없이 기존 반응형 배치 규칙과 목록을 재사용했다. 별도 검증 프로세스로 확인했으며 회사 배포를 변경하지 않았다.

## 잔여와 다음 단계

이번 대화 도구 수정의 승인 대기·미해결 항목은 **0건**이다. 기존 화면 품질 잔여 중 검색창 배경 차이는 미재현으로 남아 있다. 다음은 동일 계정·화면 크기·서비스 이동 조건으로 배경 차이를 다시 비교해 원인을 확인하는 단계다. 확인되지 않은 문제를 해결됐다고 기록하지 않는다.
