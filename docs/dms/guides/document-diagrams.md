# 문서 다이어그램 사용 안내

> 갱신: 2026-09-18 · 승인-15 범위

문서의 `mermaid` 코드 구역은 읽기 화면, 편집 미리보기, 템플릿 미리보기에서 도형으로 표시한다. 순서도·요청/응답·일정·관계 도식을 대표 구문으로 검증했다. 모든 외부 구문과 확장 문법의 호환성을 보장하는 목록은 아니다.

## 보기와 편집

- `원문 보기`를 누르면 원래 구문을 선택·복사할 수 있고, `도형 보기`로 돌아간다.
- 문서 안 검색은 기존처럼 원문을 검색한다. 일치하는 도식은 원문과 검색 위치를 보여주고, 검색을 지우면 도형으로 복귀한다.
- 긴 도식은 도식 영역 안에서 가로로 이동한다. 해당 영역에 키보드 초점을 둔 뒤 방향키로도 이동할 수 있다.
- 편집 중 기존 `미리보기`에서 도형을 확인하고 `원본보기`로 편집을 계속한다. 도형 생성 때문에 문서 원문을 바꾸거나 자동 저장하지 않는다.
- 좁은 문서 영역에서는 목차·검색·문서 첨부·확대/축소 도구가 줄을 나누어 배치된다.

## 표시 실패와 출력

잘못되거나 지원하지 않는 구문은 `다이어그램을 표시할 수 없어 원문을 보여드립니다.` 안내와 원문을 표시한다. 다른 정상 도식과 일반 본문은 계속 볼 수 있다. 일시적인 부품 로딩·생성 실패에는 `다시 시도`가 나타난다. 외부 이미지를 불러오거나 스크립트 등을 포함한 도식은 안전한 표시를 위해 원문으로 남을 수 있다.

기존 PDF 다운로드는 브라우저 인쇄 창을 연다. 도형 준비를 마친 인쇄 자료를 사용하며, 실패한 도식은 안내와 원문으로 출력한다. 마크다운 다운로드는 도형 이미지로 바꾸지 않고 문서 원문을 유지한다. 실제 PDF 저장 대상과 프린터 선택은 브라우저·운영체제에 따른다.
