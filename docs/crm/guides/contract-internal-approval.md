# 계약 초안 승인 사용 방법

> 작성: 2026-09-17 · 적용 범위: 계약 원장에 저장한 계약 초안

## 요청하기

1. **계약 원장**에서 계약을 선택하고 문서 초안을 저장한다. 이미 저장한 초안이 있으면 내용을 먼저 확인한다.
2. **계약 초안 승인 → 승인 요청할 초안 확인**에서 이번 요청의 내용을 확인한다.
3. **승인자** 한 명을 선택하고 **승인 요청**을 누른다.

본인은 승인자로 지정할 수 없다. 계약 조회 권한과 해당 초안의 열람 권한을 가진 활성 사용자만 후보에 표시된다. 대상자가 없다면 기존 문서 관리의 공유 설정으로 열람 권한을 확인한다. 승인 요청이 문서 공유 권한을 자동으로 넓히지는 않는다.

## 처리하기

승인자는 **계약현황 → 내 승인 대기**에서 계약을 선택한다. **요청 당시 초안 확인**으로 보관된 내용을 읽은 뒤 **승인** 또는 **반려**를 누른다. 반려 시 사유는 필수다. 지정된 승인자 본인만 처리할 수 있으며 관리자도 대신 승인할 수 없다.

요청자, 승인자, 요청·처리 시각과 반려 사유는 **처리 이력**에서 확인한다. 이력의 초안 열람에도 원본 문서의 현재 열람 권한이 필요하다.

## 변경·철회·재요청

진행 중인 요청은 요청자가 **요청 철회**로 끝낼 수 있다. 승인자가 바뀌었거나 계정을 사용할 수 없는 경우에도 철회 후 새로 지정한다. 반려된 요청은 필요한 내용을 수정한 뒤 다시 요청한다.

요청 후 계약이나 초안이 바뀌면 오래된 요청은 승인할 수 없다. 요청자가 철회하고 최신 초안을 확인해 다시 요청한다. 이미 승인한 초안이 바뀌어도 과거 처리 이력과 요청 당시 내용은 보존되며, 현재 초안의 승인 완료로 표시하지 않는다.

통신 오류가 나면 입력을 유지한 상태로 재시도하거나 **승인 새로고침**으로 결과를 확인한다. 같은 요청의 재전송과 같은 결정의 재시도는 이력을 중복 생성하지 않는다.

## 승인 범위

이 기능은 **요청 당시 저장된 계약 초안**을 승인한다. 자동 생성되는 역할별 기록과는 별개이며, 배포 문서의 전자서명이나 여러 단계의 결재선은 포함하지 않는다. 기존 계약 확정·청구·문서 다운로드 조건에는 새 승인 의무를 추가하지 않았다.
