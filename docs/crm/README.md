# CRM 문서

> 작성: 2026-06-08
> 최종 업데이트: 2026-08-28

이 폴더는 외부 영업관리 데모를 SSOO 프레임워크와 디자인 문법에 맞게 이식하기 위한 CRM 정본 문서입니다.

데모 100% 이식 여부는 [CRM 원천 기능 패리티 매트릭스](./planning/source-parity-matrix.md)의 `SRC-01~28`과 [CRM 원천 UI/UX 패리티 명세](./planning/source-uiux-parity-spec.md)의 `UX-01~17`을 함께 기준으로 판정합니다. 정확한 산식, 기존 verifier의 직접 검증 범위, 폐쇄 원장과 현재 revision 증명의 차이는 [CRM 데모 100% 이식 검증 계약](./planning/demo-100-verification-contract.md)을 따릅니다. 보호 소개자료는 보조 자료이며 필수 분모가 아닙니다.

데모 패리티와 운영 런칭 준비는 서로 다른 판정입니다. CRM의 운영·제어·관리 런칭 준비는 [CRM 런칭 운영 PRD](./planning/launch-operations-prd.md)의 `OPS-01~17`, 외부 배포 입력 `OPS-18`/`EXT-01~02`, [CRM·DMS 런칭 운영 브라우저 검증 계획](./planning/launch-operations-test-plan.md)의 `BT-01~27`을 모두 충족해야 완료로 판정합니다.

CRM 견적 상세는 `/api/crm/opportunities/:id/quote-preview`에서 DMS 견적 초안 readiness, `crm-quote-v1` active template source path, draft path hint, DMS 견적 lifecycle을 제공하고, 준비 완료 견적은 `/api/crm/opportunities/:id/quote-dms-document-draft`로 markdown 초안을 DMS 파일 서비스에 저장한 뒤 `crm.crm_quote_dms_handoff_m`에 문서/변수/lifecycle snapshot을 남깁니다. `/api/crm/opportunities/:id/quote-dms-document-lifecycle-execution`은 DMS 서비스가 만든 template-version/template-review record와 DOCX/PDF artifact evidence를 같은 active handoff lifecycle에 반영하고, `/api/crm/opportunities/:id/quote-dms-document-execution-evidence`는 외부 DMS 실행 결과도 같은 수신 계약으로 기록합니다. DMS 설정의 관리자 템플릿 목록은 `crm-quote-v1` reviewConfirmation 검토 확정 상태를 관리합니다. CRM 계약 상세는 `/api/crm/contracts/:id/dms-document-preview`를 읽어 문서 변수와 차단 사유, deterministic 초안 경로, 저장된 초안 경로, 최신 handoff id/status/savedAt, CRM markdown 초안부터 DMS 템플릿 검토/첨부 확인/Word 산출/PDF 저장/승인까지의 lifecycle checklist를 표시하고, DMS registry의 `crm-contract-v1` active 템플릿 source path를 검토 단계 evidence로 사용합니다. 준비 완료 계약은 `/api/crm/contracts/:id/dms-document-draft`로 markdown 초안을 DMS 파일 서비스에 저장한 뒤 `crm.crm_contract_dms_handoff_m`에 문서/변수/첨부/lifecycle snapshot을 남깁니다. `/api/crm/contracts/:id/dms-document-lifecycle-execution`은 DMS 서비스가 생성한 export policy record, 템플릿 버전 snapshot, 템플릿 변경 검토, 템플릿 변경 요청 원장, 첨부 확정 원장, 승인 route policy, 공용 사용자/조직 directory snapshot, 결재선 원장 동기화 기록, DOCX/PDF, 검토/첨부/승인 workflow artifact evidence를 CRM handoff에 반영하고 `/contracts`에서 governance evidence를 함께 표시합니다. DMS 설정의 `CRM 계약 결재선`은 계약 승인 route 정책과 required roles를 관리하고, `CRM 계약 산출 정책`은 markdown evidence와 Word/PDF artifact의 조직 scope별 산출 경로를 관리합니다.
- DMS 첨부 확인 lifecycle은 CRM에서 공급자 CI와 청구계획 별첨 evidence path를 표시하고, 공급자 CI 참조는 DMS working tree/storage adapter 기준으로 검증한 뒤 DMS 실행 시점에 첨부 확정 원장으로 보존합니다.
- DMS 실행 evidence 수신은 초안 handoff가 존재할 때만 허용하며, active handoff row를 교체해 이전 snapshot을 `replaced`로 남깁니다.
- 계정, 권한, 법인, 조직, 관리자 운영은 CRM 내부가 아니라 공용 Admin/공용 권한 모델로 관리하는 전제를 반영했고, `/operations` 운영 기준 Preview에서 CRM이 소유하지 않는 항목을 명시합니다.
- 소개자료 보호 여부는 데모 실행 코드 이식과 런칭 운영 준비의 범위·분모·잔여 과제에서 제외합니다.
