# 게시판 생성

> 2026-09-16 · 승인-03

게시판 관리 권한이 있는 사용자는 목록의 ‘새 게시판’에서 생성 창을 연다. 코드(50자)·이름(200자)·유형은 필수이며 설명(1,000자)은 선택이다. 유형은 일반·공지사항·질문답변·인력 모집이다. 화면은 공백 필수값·길이·유형을 검사한다.

입력 후 생성하거나 취소한다. 저장 중에는 입력과 취소·닫기 및 중복 제출을 막는다. 중복 코드는 기존 서버 거절을 안내하며, 실패하면 입력을 유지하고 재시도한다. 취소 후 새 창은 빈 입력으로 시작하며 크기 전환만으로 입력을 버리지 않는다.

생성 성공 시 실제 응답을 확인하고 목록을 다시 읽는다. 생성 확인에는 해당 게시판을 여는 링크를 제공한다. 기존 목록은 첫 20개만 읽으므로 새 항목이 그 밖에 있어도 이 링크로 상세를 확인할 수 있다. 전체 페이지 탐색이나 생성 확인 상태의 새로고침 복원을 새로 구현한 것은 아니다.

목록 갱신만 실패하면 생성 완료와 실패 이유를 함께 표시하고 목록만 다시 불러온다. 재시도로 게시판 생성 요청을 반복하지 않는다. 일반 목록에 보이는 새 게시판의 카드 선택·상세·새로고침은 기존 동작을 따른다.

화면의 관리 권한과 서버의 `canManageBoards` 기준을 유지한다. 열람 전용 계정은 생성 버튼이 비활성화되며 직접 생성 요청도 거절된다. 기존 서버 요청/응답·정렬·상세·게시물·문서 업무 계약을 변경하지 않았다. 서버에 없는 공백/유형 검증까지 구현됐다고 해석하지 않는다.

검증: `node scripts/verify-board-creation.mjs`와 [실제 실행 결과](../../../common/explanation/architecture/2026-09-16-board-creation-handoff.md)를 따른다.
