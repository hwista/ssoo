# 게시물 공유와 단건 보기

> 2026-09-17 · 승인-05 중 사용자가 승인한 공유 단계 · 링크/이미지 첨부와 별도

## 화면 동작

기존 게시물 카드의 공유 버튼은 `게시물 공유` 창을 연다. 글 주소를 복사하면 성공을 안내하며, 브라우저의 복사 기능을 사용할 수 없거나 거절되면 선택 가능한 읽기 전용 주소와 수동 복사 안내를 제공한다. 닫기와 키보드 취소 뒤 공유 버튼으로 초점을 돌리고 작성 중인 댓글·게시물 입력을 보존한다. 주소가 바뀌면 이전 공유 창을 닫는다.

공유 주소는 현재 커뮤니티 사이트의 `/post/:id`다. 로그인 전에는 기존 로그인 화면을 거쳐 같은 주소로 돌아온다. 로그인 후 기존 틀의 `게시물` 탭에서 작성자·본문·공개 범위·활성 댓글 수와 기존 댓글/좋아요/북마크 동작을 사용한다. 공유는 링크 전달이며 기존 열람 권한을 확대하지 않는다.

없는 글·삭제된 글·공개 범위 밖의 글은 같은 `게시물을 볼 수 없습니다.` 안내로 처리한다. 통신 실패에는 `게시물을 불러오지 못했습니다.`와 다시 시도를 제공한다. 상단의 피드로 이동은 두 경우 모두 유지한다. 재조회가 거절되면 이전에 받아 둔 카드도 숨긴다.

## 조회와 권한

새 `GET /sns/feed/posts/:postId`는 로그인과 `canReadFeed` 기능 권한을 검사한다. 기존 피드의 공개 범위 조건과 같은 정책으로 해당 글을 찾은 뒤 피드 카드와 같은 작성자·태그·댓글 수·현재 사용자의 반응 정보를 조합한다. 첫 피드 페이지에 없는 글도 직접 조회하며, 조회 수나 게시물은 수정하지 않는다.

잘못된 형식·데이터베이스 범위를 넘는 식별자는 조회 전에 거절한다. 글이 없거나 열람 조건에서 제외된 경우 작성자나 반응 정보를 추가로 조회하지 않는다. 기존 `/sns/posts/:id`의 응답·조회 수 처리, 목록·작성·댓글·반응 요청 형식은 그대로다.

새 화면 조회는 사용자와 게시물별로 구분하고 취소 신호를 전달한다. 기존 공용 계정 전환 시 캐시 초기화를 유지한다. 활성 게시물 탭 진입과 브라우저 복귀 시 새로 확인하고, 댓글·반응 저장 후에는 기존 게시물 갱신 흐름으로 재조회한다. 서버가 응답하기 전까지 이미 확인한 내용을 즉시 원격 회수한다고 보장하지 않는다. 권한은 매 요청에서 검사하며, 재조회 거절 후 이전 내용을 남기지 않는 것이 검증 범위다.

## 주소와 기존 화면 보존

글마다 고유 탭을 사용하고 주소 입력·탭 선택·닫기·방문 기록을 연결한다. 게시물에서 사이드 메뉴·사용자 메뉴·상단 검색으로 이동할 때도 해당 목적지 주소를 사용한다. 상단 검색은 기존 검색어별 탭 식별자·제목과 맞춰 중복 탭을 만들지 않는다. 검색 요청이나 결과 동작을 변경하는 범위는 아니다.

16개 탭 한도에서 새 게시물을 열 수 없으면 안내와 다시 시도를 제공한다. 기존 탭을 자동으로 닫거나 자동 저장하지 않는다. 기존 본문은 숨긴 상태로 유지하여 미저장 입력을 지키고, 사용자가 탭을 닫은 뒤 새 글을 열 수 있게 한다.

이번 제품 변경은 커뮤니티 화면과 커뮤니티 피드 조회에 한정된다. 공용 패키지 소스·다른 네 서비스 화면·문서관리 계약을 변경하지 않는다. 링크 첨부·이미지 첨부 버튼은 후속 승인·구현 대상이다.
