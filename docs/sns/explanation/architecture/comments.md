# 홈 피드 댓글 열람·작성

> 2026-09-16 · 승인-04

홈 피드 게시물의 댓글 버튼 또는 댓글 수를 누르면 목록과 작성 영역을 펼치고 다시 누르면 접는다. 게시물을 읽을 수 있는 사용자는 댓글을 열람하며, 댓글 작성 권한이 있는 사용자에게 입력과 등록을 제공한다. 기존 게시물 공개 범위와 서버 권한 검사를 유지한다.

목록은 기존 서버의 활성 댓글을 시간 순으로 표시한다. 답글은 원문 내용의 일부를 함께 표시하며, 원문이 조회되지 않더라도 해당 답글 본문을 누락하지 않는다. 작성자 이름은 기존 프로필 조회를 사용한다. 이름 조회 실패는 댓글 본문과 구분해 재시도한다.

빈 댓글·공백만 있는 댓글을 화면에서 차단한다. 등록 중에는 입력·등록을 잠그고, 실패하면 입력을 유지한다. 성공하면 입력을 비우고 댓글 목록과 피드의 댓글 수를 다시 읽는다. 숫자도 목록과 같이 활성 댓글만 센다. 등록 후 목록 갱신만 실패하면 등록 완료를 유지하고 목록만 다시 불러온다.

접기·펼치기와 화면 크기 전환에서는 미저장 입력을 보존한다. 페이지 새로고침 이후 입력 복원은 제공하지 않는다. 댓글 수정·삭제·답글 작성·댓글 반응과 공용 프로필 내 댓글 입력은 이번에 구현한 기능이 아니다.

후속 승인-21에서 답글 생성 시 같은 게시물의 활성 원문만 허용하도록 보정했다. 다른 게시물·비활성·없는 원문은 저장 전에 거절하며 기존 정상 답글 깊이·권한·응답 형식을 유지한다. 일반 댓글 입력은 원문 번호를 전송하지 않는다.
