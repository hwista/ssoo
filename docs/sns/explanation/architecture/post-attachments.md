# 커뮤니티 링크·이미지 첨부

> 2026-09-17 · 사용자 승인-05 통합 첨부 범위 · 구현·검증 완료

## 화면 동작

링크 아이콘은 주소 입력 창을 연다. `http://` 또는 `https://` 웹 주소를 검사해 본문 끝에 새 줄로 추가한다. 취소하면 기존 입력을 유지한다. 주소에 사용자명·비밀번호를 포함한 형식, 공백·제어 문자와 다른 스킴은 허용하지 않는다. 외부 사이트 제목이나 대표 사진을 수집하지 않는다.

기존 글과 새 글의 웹 주소는 피드·공유 게시물 및 게시판 본문에서 새 탭으로 열린다. 일반 본문과 HTML처럼 생긴 글자는 문자열로 유지한다. 게시판 요약에서 주소 글자가 잘려도 실제 이동 주소는 전체 원래 주소다. 공용 프로필의 별도 활동 요약 화면은 이번 변경 대상이 아니다.

사진은 최대 4장, 장당 5,000,000바이트의 JPEG·PNG·WebP다. 선택한 사진은 본문 아래 미리보기·파일명·개별 제거 버튼으로 나타난다. 파일 선택 취소·잘못된 추가 선택은 기존 본문과 사진을 유지한다. 본문 입력은 계속 필수다. 사진만 게시하는 흐름, 초안 자동 저장이나 새로고침 복원은 추가하지 않는다.

게시된 사진은 1장일 때 한 열, 여러 장일 때 두 열로 순서대로 표시한다. 전체 사진 비율을 유지하고 누르면 확대 창을 연다. 조회 실패는 해당 위치에서 안내·재시도를 제공한다. 열린 탭 이동 중 작성 초안은 보존하고 작성 취소·계정 변경은 사진 초안을 정리한다.

## 저장과 재시도

선택한 사진은 게시 전까지 브라우저 메모리에만 존재한다. 게시할 때 본문·공개 범위·사진과 작성 요청 식별자를 함께 전송한다. 기존 텍스트 전용 게시 요청은 그대로 유지한다. 저장 중에는 중복 입력을 막고, 모두 저장된 성공 응답을 받은 뒤에만 작성창을 초기화한다.

서버는 작성자와 요청 식별자별 데이터베이스 트랜잭션 잠금으로 동시 재시도를 직렬화한다. 기존 첨부 관계와 경로의 요청 식별자·내용 지문을 통해 같은 요청은 같은 게시물로 반환한다. 같은 식별자의 다른 내용과 삭제된 게시물의 재시도는 충돌로 거절한다. 파일 경로나 다른 사람의 첨부 식별자를 받아 재사용하는 입력은 없다. 데이터 구조 변경이나 새 마이그레이션은 없다.

응답 유실처럼 게시 결과가 불확실하면 본문·공개 범위·사진·요청 식별자를 유지한다. 사용자는 같은 내용으로 재시도하여 기존 성공 결과를 확인할 수 있다. 검증 오류처럼 확정된 입력 거절이면 수정 가능 상태로 돌아간다. 글이나 사진 일부만 저장된 결과를 성공으로 표시하지 않는다.

파일은 시도마다 다른 하위 폴더에 쓴다. 트랜잭션 제한 시간을 지난 이전 요청의 정리가 나중에 성공한 재시도의 파일을 지우지 않게 한다. 처리 중 확인한 실패는 해당 시도의 파일과 빈 부모 폴더를 정리한다. 프로세스 중단·커밋 결과 불확실 등으로 남은 파일은 시작 시와 매시간 검사하여 24시간 이상 지난 미연결 요청 폴더만 같은 잠금 아래 정리한다. 연결된 파일은 보존한다. 논리 삭제한 글의 첨부는 열람을 거절하며, 데이터 행 자체가 제거된 뒤에는 고아 파일 정리 대상이 된다.

## 권한과 파일 검사

이미지 실제 데이터 조회도 기존 게시물 열람 정책 및 피드 기능 권한을 검사한다. 전체 공개도 현재의 로그인 조건을 유지한다. 다른 글의 첨부 식별자, 없는/삭제된 글, 공개 범위 밖 계정은 거절한다. 이미지 응답은 비공개·저장 금지 캐시 정책을 사용하고 경로를 노출하지 않는다.

브라우저는 기존 인증 요청 도구로 이미지 데이터를 받아 임시 주소로 표시한다. 계정별 조회 키와 임시 주소 정리를 적용하며, 재조회에서 거절되면 이전 이미지를 계속 보여주지 않는다. 권한 철회 이전에 사용자가 따로 저장한 사본을 회수하는 기능은 아니다.

서버는 전송자가 선언한 크기·형식 외에 실제 바이트 수, 실제 형식과 전체 디코딩 성공을 검사한다. 손상된 이미지·위장 파일·여러 프레임 이미지와 4천만 화소를 넘는 이미지는 거절한다. 한글 파일명은 브라우저 multipart 전송 인코딩에 맞춰 보존하며 파일명으로 저장 경로를 만들지 않는다.

## 실행 환경

저장 경로는 서버의 `SNS_IMAGE_STORAGE_PATH`로 지정한다. 미지정 로컬 기본값은 서버 작업 디렉터리 아래 `.runtime/sns-images`다. 문서관리 저장소·비공개 주소·업무 계약을 변경하거나 재사용하지 않는다.

실제 운영 배포에서는 영속 저장 경로와 권한·백업/복구를 운영 출시 항목에서 확인해야 한다. 여러 서버 인스턴스를 사용하면 모두 같은 첨부 저장소를 읽고 쓸 수 있어야 한다. 이번 격리 환경 검증은 실제 운영 저장소 구성이나 운영 배포 완료를 뜻하지 않는다.
