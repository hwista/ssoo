# 네 서비스 검색 결과 가림 개선 결과

> 후속 최신: [검색 직접 접속·복원](2026-09-15-search-entry-handoff.md)에서 승인-18 완료·총 9완료·9대기를 확인한다. 아래는 승인-17 당시 기록이다.

> 2026-09-14 · 승인-17 완료 · 총 18항목 중 8완료·10승인 대기

사용자 “다음 진행”으로 승인받은 문서관리·운영관리·프로젝트·커뮤니티의 검색 패널 기본 표시 개선을 완료했다. 작업공간이 부족하면 결과가 먼저 보이고, 기존 버튼으로 사용 팁·검색 기록을 열고 닫는다. 충분히 넓으면 기존 나란히 배치를 유지한다. 고객관리는 앞선 승인-16 결과를 유지했다.

제품 변경은 각 서비스의 검색 화면에서 기존 공용 선택값을 지정하는 한 줄씩, 총 네 줄이다. 공용 기본값·패널 조작·검색 요청/응답·권한·문서 본문·문서 열기/편집/저장 계약은 수정하지 않았다. 사용자 검수 완료 기준을 이번 패널 변경 외의 수정 권한으로 확대하지 않았다.

## 검증과 한계

- **다섯 앱 새 빌드 통과**: 고객관리·운영관리·프로젝트·커뮤니티는 의존 작업 포함 8/8, 캐시 재사용 0. 문서관리는 보존 검사와 새 빌드를 별도로 통과했다.
- **최종 관련 회귀 15/15 통과**: 네 서비스 패널 4건, 기존 고객관리 입력/저장·검색·탭 한도 7건, 문서관리 관련 업무 4건. 전체 서비스의 모든 기능이나 문서관리 전체 검수 재완료를 뜻하지 않는다.
- **직접 브라우저 확인**: 네 서비스 × 세 크기에서 결과·조작을 확인하고 서비스별 두 번의 넓은 화면↔작은 화면 왕복을 통과했다. 결과 제목의 실제 화면 좌표가 패널에 가려지지 않는지 검사했다. 최종 정상 검색 흐름의 요청·콘솔·실행 오류는 0건이었다. 로그인 전 기존 세션 거절 응답은 승인-09로 별도 유지한다.
- **문서 회귀 자료 정리**: 격리 검증에서 생성한 문서 다섯 건의 삭제 응답 모두 성공을 확인했다. 실제 운영 자료나 운영 배포를 사용하지 않았다.
- 사전 검사·타입·코드 패턴·문서·규칙 동기화 및 작업본/실행물 대조는 [실행 결과](../../../../output/playwright/approval17-search-panel-20260914/results.md)를 따른다.

최초 두 검사 묶음은 각각 2통과·2실패였으며 원본을 보존했다. 첫 묶음은 아래 직접 접속 결함을 발견했다. 두 번째 묶음은 프로젝트 새로고침 시 검색 탭 보존을 가정한 검사와 문서관리 빈 입력 동작을 잘못 가정한 검사에서 실패했다. 프로젝트 탭 복원은 미해결로 기록하고 문서관리 검사는 기존 결과 유지 동작에 맞췄다. 최종 패널 회귀 통과에 직접 접속·탭 복원 해결을 포함하지 않는다. 별도 문서관리 캡처 중 재렌더로 제목 요소가 교체된 중단 기록도 보존하고 현재 요소를 읽어 재실행했다.

빌드 후 제품 소스는 그대로다. 새 패널 검사 한 파일만 위 실제 진입 동선에 맞게 수정한 뒤 통과했고 이후 정본 문서만 갱신했다. [최종 대조](../../../../output/playwright/approval17-search-panel-20260914/final-reconciliation.json)에서 이 차이와 다섯 앱·서버 실행물 동일성을 구분한다. 구조·불필요 변경 검토는 동일 에이전트가 수행했으며 독립 검토 승인을 주장하지 않는다.

## 남은 문제와 다음 승인안

**승인-18: 프로젝트·문서관리의 검색 주소 직접 접속 및 검색 복원.** 두 서비스는 검색 주소 직접 접속·해당 주소 새로고침 시 검색 화면이 열리지 않았다. 두 크기에서 직접 접속/새로고침 총 8회로 확인했다. 관련 경로 소스는 이번 수정 전과 같으며, 과거 빌드를 별도로 브라우저 재현한 증거와는 구분한다. 프로젝트에서는 루트 새로고침 후 저장 탭이 홈만 남는 동작도 관찰했다. 이 항목들은 수정하지 않았다.

다음 승인안은 기존 검색 화면 틀과 탭을 직접 접속·새로고침에도 연결하고 검색어·필터를 복원하는 것이다. 프로젝트는 동일 사용자 새로고침의 검색 복원을 함께 진단·수정하되, 사용자 변경·로그아웃의 상태 정리 보호는 유지한다. 문서관리 문서 업무·권한·연동 계약은 보존한다. [구체적인 변경안과 검증 단계](../../../../output/playwright/approval17-search-panel-20260914/next-approval-proposal.md)를 준비했으며 사용자 승인 후 진행한다.

승인 대장은 **8/18 완료(44.4%)·10대기**다. 새 결함 1항목을 추가한 승인 처리 비율이며 기능 구현률이나 출시 준비율이 아니다. **실제 운영 증거 0/5**는 그대로 남아 있다.
