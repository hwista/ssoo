# 커뮤니티 댓글 열람·작성 작업 결과

> 2026-09-16 · 승인-04 완료 · 총 21항목 중 14완료·7승인 대기

> 후속 승인-21 답글 원문 검사도 완료했다. 현재 15완료·6대기는 [최신 핸드오프](2026-09-16-reply-parent-handoff.md)를 따른다. 아래 수치·미적용 제안은 승인-04 종료 당시 기록이다.

사용자 “좋아 다음 진행”으로 직전 댓글 열람·작성안을 승인받았다. 기존 댓글 버튼과 숫자를 댓글 목록 및 일반 댓글 입력에 연결했다. 수정 전에는 클릭해도 댓글 요청·입력 창이 없음을 실제 브라우저로 확인했다.

| 기능·화면 | 확인 결과 |
|---|---|
| 댓글 열람 | 버튼·댓글 수로 펼침/접기, 빈 목록·조회 실패·재시도 표시 |
| 기존 댓글·답글 | 활성 댓글 전부와 작성자 이름·시각 표시. 답글은 원문을 참조하고 원문이 비활성이어도 답글 본문 보존 |
| 작성자 정보 | 기존 프로필 조회 재사용. 실패해도 본문을 유지하며 작성자만 재조회 |
| 댓글 작성 | 공백 차단·등록 중 중복 제출 방지·실패 입력 보존·성공 후 실제 목록과 숫자 갱신 |
| 미저장 입력 | 접기·펼치기 및 화면 크기 전환에서 보존. 새로고침 영구 복원은 이번 구현 범위가 아님 |
| 저장 후 조회 실패 | 등록 성공을 유지하고 댓글 목록만 재조회, 재등록 없음 |
| 권한 | 열람 전용 계정은 목록 조회 가능·입력 없음·직접 작성 거절. 일반 작성 권한은 등록 가능. 비공개 게시물 댓글 조회/작성 거절 |
| 댓글 수 | 비활성 원문 1건이 있던 자료에서 숫자 5·활성 목록 4의 기존 불일치를 확인하고 활성 댓글 4로 집계 수정 |
| 이전 기능 | 게시판 생성·상세·새로고침, 두 크기의 프로필 반응·북마크 즉시 반영·편집 취소 통과 |

## 범위와 검증

큰 화면 1440×1000과 작은 화면 390×844의 실제 브라우저 검사를 통과했다. 관련 서버 검사 8/8, 새 서버 빌드 3/3 및 새 커뮤니티 빌드 5/5(각 의존 작업 포함·캐시 0)를 확인했다. 브라우저 기능/회귀 최종 8실행 묶음과 별도 답글 결함 재현 1실행을 구분한다. 일반 댓글 실제 저장 4건·답글 결함 재현 1건을 확인했다. 공백·열람 전용·비공개 거절·미저장 입력에 해당하는 저장은 없었다.

댓글 수 보정을 제외한 서버 권한·요청/응답 형식, 공용 패키지, 문서관리를 포함한 다른 네 웹 앱 제품은 변경하지 않았다. 댓글 편집·삭제·답글 작성·댓글 반응 조작, 공용 프로필의 댓글 열람/작성 화면을 새로 구현했다고 해석하지 않는다. 이번 입력은 커뮤니티 홈 피드의 댓글이다.

최초 검사는 실제 카드에 없는 선택자를 사용한 경우와 검사 도구의 미지원 대기 함수를 사용한 경우에 실패했다. 검사만 보정해 다시 통과했으며 원본 실패를 보존했다. 로그인 전 세션 확인의 기존 401은 승인-09로 유지한다. 실패 복구를 위해 주입한 500과 권한 거절 403/404는 정상 사용 오류와 구분한다. 최종 로그인 후 검사에서는 요청 실패·콘솔·실행 오류가 없었다. 구조 검토는 같은 에이전트 직접 검토이며 독립 검토자 승인이 아니다.

고객관리 입력·저장·확정 잠금 2/2와 문서관리 기존 업무 4/4도 통과했다. 검사 소유 자료와 문서 회귀 생성 자료를 정리하고, 원래 게시판과 시작 전 자료 건수를 대조했다. 감사 이력·번호 시퀀스까지 되돌렸다는 의미는 아니다. 최종 소스/빌드 대조는 실행 증거를 따른다.

## 새로 발견한 문제와 다음 작업

기존 답글 요청은 원문 댓글이 같은 게시물에 속하는지 검사하지 않는다. 일반 작성 계정의 비공개 댓글 조회는 404로 거절되지만 해당 번호를 공개 게시물 답글의 원문으로 지정하면 201로 저장되는 것을 격리 자료로 재현했다. 비공개 원문 본문이 조회되었다는 의미는 아니다. 새 일반 댓글 입력은 원문 번호를 전송하지 않는다.

이를 **승인-21 답글 원문 연결 검증**으로 별도 기록했다. 같은 게시물의 활성 원문만 허용하고 다른 게시물·없는/비활성 원문은 저장 없이 거절하는 [검토안](../../../../output/playwright/approval04-comments-20260916/approval21-proposal.md)을 준비했다. 이 답글 생성 계약 수정은 아직 적용하지 않았다.

완료 +1·신규 +1로 **총 21항목 중 14완료·7승인 대기**로 반영했다. 승인 처리율은 출시 준비율이 아니다. 운영 증거 0/5는 그대로 미완료다. [실행 증거](../../../../output/playwright/approval04-comments-20260916/results.md)를 함께 본다.
