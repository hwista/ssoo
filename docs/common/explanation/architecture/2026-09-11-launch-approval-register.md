## 검토 형식

최신 재현과 구체적인 제안·검증 조건은 [승인 검토 자료](../../../../output/playwright/launch-ralph-20260911/approval-review.md)에 14개 항목을 모았다. 우선순위는 일반 데이터 표시, 기본 등록 필수 항목, 운영 의존성 검사 실패, 세 서비스의 크기 전환 시 입력 보존이다. 일반 데이터 제외는 검증 전용 환경에서 실제 신규 저장·재조회·기본 현황 누락까지 확인했다. 커뮤니티 검색·댓글·공유·이미지·링크도 입력·클릭 후 실행 연결 부재를 확인했다.

각 항목은 재현 화면, 현재 동작, 제안 동작, 영향받는 서비스, 보존할 기능·계약, 검증 방법을 갖춘 뒤 사용자에게 제시한다. 현재 표의 코드 확인 항목은 후보이며 사용자가 승인한 설계가 아니다. 사용자 결정은 날짜와 승인된 범위를 함께 기록한다.
