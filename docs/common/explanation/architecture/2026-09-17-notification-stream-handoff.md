# 알림 연결 오류 — 수정 및 검증 기록

> 작성: 2026-09-17 · 상태: 수정·검증 완료 · 기존 관찰 문제의 후속 처리

## 승인과 범위

사용자는 앞서 관찰한 문서관리 알림 연결 오류의 재현·내부 수정·재접속·로그인 만료·기존 문서 작업 검증을 승인했다. 같은 코드를 사용하는 관리·고객관리·프로젝트·문서관리·커뮤니티를 함께 확인한다. 별도 승인 번호나 완료 건수를 추가하지 않는다. 기존 화면·사용 방법·요청/응답 데이터·권한·재시도 간격은 유지한다.

## 확인한 원인과 수정

실제 문서관리 브라우저에서 인증이 거절된 알림 요청을 보냈을 때 `ERR_CONTENT_LENGTH_MISMATCH`를 재현했다. 프록시는 서버 오류 본문을 기존 재시도 안내로 바꾸면서 원래 응답 길이 179를 전달했고, 브라우저는 새 본문과 길이가 달라 응답 수신을 실패했다.

공통 알림 스트림의 응답에서 이전 본문에 속한 길이·압축·전송 프레이밍 정보만 제거한다. 실제 송신 서버가 현재 본문의 프레이밍을 결정한다. 스트림 중간 오류에 재시도 안내를 덧붙이거나 압축 해제된 응답을 전달할 때도 같은 처리가 필요하다. 파일 다운로드의 길이·파일명·본문 전달과 로그인 쿠키·추적 정보는 보존한다.

제품 변경은 공통 프록시 한 함수의 5줄이다. 화면, 서비스별 경로, 서버 업무 처리, 데이터 구조, 알림 내용과 재접속 정책은 바꾸지 않았다.

브라우저 검증은 실제 로컬 격리 서버를 사용했다. 연결 장애와 만료는 검증용 브라우저에서 주입했으며 운영 장애 복구 증거로 대체하지 않는다. 근거는 `output/playwright/notification-stream-20260917/`에 보존한다. `baseline.json`, `tests-before.log`, `tests-final.log`, `stable-reconnect.json`, `session-expiry.json`, `cross-service.json`, `dms-final.json`, `cleanup.json`, `preservation.json`과 빌드·가드 로그를 함께 확인한다. 설계·불필요 변경 검토는 같은 작업자가 수행했으며 독립 검토자의 승인으로 주장하지 않는다. 검토 후 공통 실행 검사 50건을 재실행했다. 검증용 문서 5개는 기존 시험의 정리 절차로 삭제했고, 활성 문서·잔여 파일 0을 읽기 전용으로 확인했다.

## 진행률과 다음 작업

승인 대장은 **22항목 중 19완료·3잔여**, 실제 운영 증거는 **0/5**다. 이번 작업은 이미 관찰한 문제의 후속 수정이며 새 승인 항목으로 집계하지 않는다. 잔여는 운영 환경, 프로젝트 설정의 실제 적용 범위, 문서 내 다이어그램 표시 결정이다. 프로젝트 설정이나 문서 표시 변경은 이 알림 수정 승인에 포함하지 않는다. 운영 배포·커밋·푸시는 하지 않는다.
