# 고객관리 통합 검색 접속 복구 결과

최신 후속 결과는 [검색 결과 가림 개선 핸드오프](2026-09-14-crm-search-panel-handoff.md)를 따른다. 승인-16은 이후 완료됐으며 아래는 승인-08 종료 당시 기록이다.

> 2026-09-14 · 승인-08 완료 · 총 16항목 중 6완료·10승인 대기

검색 주소로 직접 접속하거나 새로고침하면 홈이 열리던 문제를 수정했다. 기존 검색 화면·검색 요청을 연결하고 실제 자료와 두 화면 크기로 검증했다. 검색 화면 전체의 시각 품질 완료를 뜻하지 않는다. 검증 중 발견한 작은 화면의 보조 영역 가림은 승인-16으로 별도 등록했다.

## 화면·동작별 결과

| 동작 | 확인 결과 |
|---|---|
| 직접 접속·새로고침 | 검색어와 서비스 필터를 유지해 기존 검색 화면과 실제 결과를 표시한다. 검색 탭이 중복 생성되지 않는다 |
| 검색어 변경·상단 검색 | 다른 검색어는 별도 탭, 같은 검색어는 기존 탭을 사용한다 |
| 필터 변경 | 같은 검색어의 탭을 유지하면서 해당 서비스로 다시 검색한다. 결과가 0인 서비스는 기존 화면에서 필터 버튼을 표시하지 않으며, 요청·주소·빈 안내로 필터 유지를 검증했다 |
| 뒤로·앞으로 이동 | 주소와 선택된 검색 탭이 일치한다 |
| 검색어 없음·결과 없음 | 기존 안내를 각각 표시한다 |
| 열린 화면 16개 한도 | 새 검색 거절 시 현재 입력과 주소를 보존한다. 이미 열린 검색 선택과 탭 닫기 후 재시도도 된다 |
| 작은 화면 기본 표시 | 사용 팁·검색 기록이 결과를 가리는 현상이 남아 있다. 기존 접기 버튼으로 결과를 볼 수 있음을 확인했다. 기본 노출 개선은 승인-16 미적용 |

## 검증 수치와 범위

- **검색 회귀 2/2**, **기존 탭 한도·입력/저장 회귀 4/4** 통과. 각각 1440×1000·390×844에서 실행했다. 기존 등록·수정·재조회·확정 잠금과 생성 자료 정리도 통과했다.
- **직접 브라우저 2/2**: 실제 검색 결과 3건, 검색어별 탭, 필터, 빈 상태, 방문 기록, 한도 거절·초안 보존·닫기 후 재시도 확인. 로그인 이후 검증 흐름의 요청·콘솔·실행 오류 0, 업무 저장 요청 0.
- 새 고객관리 빌드 **5/5 작업**, 캐시 재사용 0. 사전·타입·코드 검사 통과. 다른 서비스 전체를 새로 빌드·검증한 수치가 아니다.
- 캡처 **6장**을 직접 열어 확인했다. 작은 화면 기본 노출 2장은 가림 증거이고, 추가 2장은 기존 접기 조작 후 결과·빈 안내가 보이는 증거다. 모든 캡처를 시각 품질 통과로 집계하지 않는다.

## 변경·보존 경계

제품 변경은 고객관리의 주소 연결 한 곳이다. 상단 검색과 같은 검색어별 탭 구분을 재사용하고 원래 주소 전체를 유지했다. 검색 화면·결과 열기·서버·권한·저장·공용 패키지와 문서관리 제품은 이번 작업에서 변경하지 않았다. 기존 사용자 수정과 이전 승인 결과를 보존했다.

구조·불필요 변경 검토는 동일 에이전트가 수행했다. 독립 검토자의 승인으로 표시하지 않는다. 빌드 이후 제품 변경은 없으며, 검색 회귀의 결과 0 필터 검사 가정만 보완했다. 최종 문서 갱신은 검증 작업본과 분리해 [작업본 비교](../../../../output/playwright/approval08-search-20260914/final-reconciliation.json)에 기록한다.

검증은 격리된 기존 데이터베이스와 새 고객관리 실행물에서 수행했다. 실제 운영 배포는 하지 않았다. 로그인 전 기존 세션 거절 응답은 승인-09로 남아 있다. 이번 검색은 기존 키워드·자료 속성 검색이며 의미 기반 검색·인공지능 답변 기능의 준비 완료 증거가 아니다.
