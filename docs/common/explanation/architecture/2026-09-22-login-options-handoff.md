# 로그인 편의 옵션 통일 핸드오프

> 작성: 2026-09-22 · 상태: 승인 적용·새 빌드·브라우저 검증 완료

## 승인과 범위

사용자는 [로그인 비교안](../../../../output/playwright/login-review-20260922/review.html)을 확인한 뒤 “진행”으로 관리·프로젝트관리·문서관리·협업의 아이디 저장 및 비밀번호 표시 옵션 적용을 승인했다. 영업관리는 이미 제공하던 기능을 유지한다.

네 앱의 기존 공용 로그인 페이지 호출에 두 옵션만 명시한다. 공용 구현·기본값, 서버 인증·세션·권한, 로그인 후 복귀 및 비밀번호 재설정/외부 로그인/가입 계약을 바꾸지 않는다. 서비스별 색상도 유지한다. 비밀번호 찾기는 아이디 저장과 같은 줄로 이동하며 기존 경로를 사용한다.

아이디 기억은 로그인 성공 시 선택된 아이디만 저장하며, 저장 해제 시 제거한다. 비밀번호 표시는 기본 숨김 상태다. 옵션은 브라우저에 비밀번호를 저장하는 기능이 아니다.

## 검증

[실제 적용 화면](../../../../output/playwright/login-apply-20260922/screens.html)과 [검증 상세 및 제한](../../../../output/playwright/login-apply-20260922/results.md)를 참조한다.

- 네 변경 앱의 새 production build 컴파일·타입 검사·생성 완료. 기존 영업관리는 소스 지문이 일치하는 검증 빌드로 회귀 확인.
- 다섯 서비스 × 네 화면 폭, 20상태에서 승인 미리보기의 카드·입력란·비밀번호 찾기 배치 일치 및 가로 넘침 0건.
- 서비스당 28개, 총 140개 검사 통과. 기본 옵션·키보드 순서·비밀번호 표시/숨기기·빈 입력 차단·재설정 화면 진입/복귀 확인.
- 실제 미등록 자격증명 거절 5건, 정상 로그인 5건, 요청한 내부 주소로 복귀 5건, 로그아웃 5건 확인. 아이디 기억·복원·해제·새로고침 후 미복원 및 비밀번호 비움 유지.
- 최종 예상 밖 브라우저 실행·통신 오류 0건. 의도한 인증 거절 401은 예상 결과로 분리 기록.
- 작업 전후 사전 검사, 규칙 동기화, 문서관리 보호 검사와 실제 작업공간 빌드, 네 변경 파일 문법·패턴 검사 및 변경 문서 검사 통과.

격리 빌드에서 Next 내부 검사 도구의 모듈 탐색 오류가 발생한 로그는 보존했다. 실제 작업공간에서 네 변경 파일 ESLint를 별도 실행해 통과했으며, 격리 빌드의 컴파일·타입 검사·생성 성공과 구분한다. 검증 스크립트의 URL 비교와 최초 시험 비밀번호 형식 오류를 보정한 뒤 최종 회귀를 수행했다.

비밀번호 재설정 요청 발송·확정은 이번 UI 옵션 변경 범위가 아니다. 실제 직원 비밀번호와 운영 배포는 변경하지 않는다.

## 다음 단계

이번 옵션 적용과 회귀 검증 이후에는 검색 결과의 내부 용어·경로 표현을 읽기 전용으로 검토하고 구체안을 제시한다. 문서관리의 별도 구성 설정 세부 품질, 아직 재현되지 않은 검색란 배경 차이는 잔여다. 화면·동작 후속 변경은 별도 승인 후 적용한다. 기존 정식 승인 22항목의 21완료·1운영 보류 집계는 유지한다.
