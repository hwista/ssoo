## 원인과 보정

읽기 화면은 비동기 도식 생성 도중 본문이 다시 삽입되어 원래 도식 대상이 분리되고 있었다. 실제 실행에서 본문 재삽입과 분리된 대상에 도형이 들어가는 순서를 관측했다. 본문 값의 객체를 안정화하고 도식 상태를 화면 생명주기에 연결했다. 편집·템플릿 미리보기와 인쇄용 문서에도 같은 도식 생성을 연결했다.

초기 구현에서 순서도·관계도 글자가 정화 과정에서 빠진 문제도 발견해 수정했다. 기존 안전한 렌더링 설정을 유지하면서 도형 안의 글자 영역을 올바르게 처리한다. 구문 오류와 일시적인 로딩 오류를 구분하고 실패한 부품 로딩은 재시도할 수 있다. 작업 중 화면·요청 계약의 추가 변경은 하지 않았다.
