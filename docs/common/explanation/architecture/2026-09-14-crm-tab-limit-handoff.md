# 고객관리 열린 탭 한도 처리 결과

최신 후속 상태는 [검색 접속 복구 핸드오프](2026-09-14-crm-search-route-handoff.md)를 따른다. 아래는 승인-11 완료 시점의 기록이다. 후속 승인-08은 완료됐고 새 승인-16을 포함해 6완료·10대기다.

> 2026-09-14 · 입력 연결 완료 / 탭 한도 문제 완료 · 승인 항목 5완료·10대기

사용자가 승인한 탭 한도 안내·현재 입력 보존·주소 복구를 적용하고 실제 브라우저 검증을 마쳤다. 앞서 완료한 입력 연결과 이번 탭 한도 문제를 각각 구분해 표시한다. 고객관리 범위의 승인-11은 이제 완료다.

## 화면·동작별 결과

| 동작 | 수정 후 확인 |
|---|---|
| 16번째 화면 열기 | 홈 포함 16개까지 기존대로 열린다 |
| 가득 찬 상태에서 새 화면 선택 | 현재 탭과 미저장 입력을 유지하고 한도 안내를 표시한다. 메뉴 선택으로 주소만 바뀌지 않는다 |
| 이미 열린 화면 선택 | 한도 상태에서도 해당 탭으로 이동한다 |
| 사용하지 않는 탭 닫기·재시도 | 15개가 된 뒤 원하는 화면을 다시 열어 16개가 된다. 다른 탭의 입력은 유지된다 |
| 주소가 먼저 바뀐 경우 | 현재 화면 주소로 복구한다. 새 방문 기록을 덧붙이지 않고 현재 기록을 교체한다 |
| 뒤로·앞으로·직접 접속·새로고침 | 주소와 활성 탭이 일치하고 안내가 반복해서 열리지 않는다 |
| 기존 영업기회 입력·저장 | 입력 연결·필수 입력·오류 표시·실제 등록/수정/재조회·확정 잠금 회귀 유지 |

한도 안내는 “열린 화면은 최대 16개입니다. 필요한 입력을 저장한 뒤 사용하지 않는 탭을 닫고 다시 선택해 주세요.”다. 기존 공용 안내 창과 확인 버튼을 사용했다. 탭 자동 닫기·자동 저장·한도 증가는 도입하지 않았다.

## 정량 검증

- **탭 한도 회귀 2/2**: 1440×1000, 390×844. 실제 메뉴로 15→16개를 포함한 증가, 거절·입력 보존·선택·닫기·재시도·주소 복구·방문 기록·새로고침 통과.
- **기존 입력·저장 회귀 2/2**: 같은 두 크기에서 필수 입력·다중 탭 이름 연결·크기 전환·실제 등록/수정/재조회·확정 잠금·생성 자료 정리 통과.
- **직접 브라우저 2/2**: 별도 실제 브라우저 세션에서 두 크기의 전체 흐름을 재실행했다. 상단 기존 새 기회 선택·사용자 설정의 한도 거절과 주소 기록 교체 호출도 확인했다. 정상 흐름 요청·콘솔·실행 오류 0, 업무 저장 요청 0.
- 새 고객관리 빌드의 의존 작업 **5/5**, 캐시 재사용 0. 사전·타입·코드·디자인 검사 통과. 다섯 앱 전체를 새로 검증했다는 뜻이 아니다.
- 안내와 입력 보존 화면 **4장**을 직접 열어 확인했다. 넓은 화면과 작은 화면 모두 안내 문구·확인 버튼을 사용할 수 있고 기존 양식 배치를 유지했다.

입력 보존은 현재 문서 안의 메뉴·탭 이동과 주소 복구를 대상으로 한다. 브라우저 전체 새로고침이나 주소창을 통한 문서 재로드 뒤에는 기존 탭 복원·주소 일치를 검증했으며 미저장 초안의 영구 보관 기능을 구현했다고 주장하지 않는다. 로그인 전 기존 세션 거절은 승인-09로 남긴다. 필수 입력 회귀의 의도적인 공백 거절 응답은 검증한 오류 상태다.

## 변경·검증 경계

제품 변경은 고객관리의 탭 상태와 화면 이동을 담당하는 다섯 파일이다. 탭 닫기·선택·정렬 처리 자체, 업무 저장·권한·필수 항목·서버 계약은 유지했다. 기존 공용 화면 틀을 유지한 채 한도 안내를 별도로 표시한다. 문서관리와 다른 서비스 제품, 공용 패키지는 이번에 변경하지 않았다.

정적 화면 검사 한 곳은 기존 인라인 인자를 찾는 문자열을 변경된 주소 인자로 맞췄으며 검증 목적은 유지했다. 새 두 크기 회귀를 추가했다. 빌드 후 검사 파일의 닫기 버튼 대상과 화면 안정화 대기를 보완했지만 제품은 재수정하지 않았다. [작업본 비교](../../../../output/playwright/approval11-tabs-20260914/final-reconciliation.json)에서 빌드·검증·문서 갱신 지문을 구분한다.

구조·불필요 변경 검토는 동일 에이전트가 수행했고 독립 검토자의 승인으로 표시하지 않는다. 추가 제품 수정 없이 최종 회귀와 브라우저를 통과했다. 기존 사용자 수정 및 이전 승인 결과를 보존했다.

- 총 승인 항목은 **15개 중 5개 완료·10개 대기**다. 실제 운영 증거 **0/5**는 별도로 남아 있으며 출시 완료가 아니다.
